## 🚀 Cara Menggunakan

### 1. Setup Repository
```bash
# Buat repository baru dengan nama username GitHub Anda
# Contoh: jika username = yubiwangak19, buat repo "yubiwangak19"

# Clone dan setup
git clone https://github.com/yubiwangak19/yubiwangak19.git
cd yubiwangak19

# Copy semua file dari folder ini ke repository Anda
# Commit dan push
git add .
git commit -m "✨ Add awesome GitHub profile"
git push origin main
```

### 2. Kustomisasi
- Edit informasi personal di `README.md`
- Ganti username di semua URL statistik
- Update social media links
- Sesuaikan tech stack badges
- Tambahkan project repositories

### 3. Aktivasi GitHub Actions
- Pergi ke Settings > Actions
- Enable "Allow all actions"
- Set "Read and write permissions"
- Manual trigger snake workflow jika perlu

### 4. Preview Lokal
```bash
# Install dependencies
npm install

# Start preview server
npm start

# Atau buka langsung
open preview.html
```

## 🔧 Troubleshooting

### Snake Animation Tidak Muncul
1. Pastikan GitHub Actions enabled
2. Check workflow permissions
3. Manual trigger workflow
4. Tunggu beberapa menit

### Stats Tidak Loading
1. Periksa username di URL
2. Pastikan repository public
3. Coba refresh cache
4. Ganti theme jika error

### CSS/JS Tidak Bekerja
1. Check path file
2. Validate syntax
3. Test di browser lain
4. Clear cache
