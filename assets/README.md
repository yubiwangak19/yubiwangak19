# 📁 Assets Folder

Folder ini digunakan untuk menyimpan aset-aset profil GitHub seperti:

- 📸 Foto profil
- 🖼️ Banner/header images  
- 🎨 Icon dan logo
- 📊 Screenshot project

## 📝 Cara Upload Foto JPEG:

1. Simpan foto profil JPEG Anda di folder ini dengan nama `profile-photo.jpeg` atau `profile-photo.jpg`
2. URL sudah diupdate di README.md untuk menggunakan:
   ```
   ./assets/profile-photo.jpeg
   ```

## 🎯 Mengapa JPEG?
- ✅ **File size lebih kecil** - Loading lebih cepat
- ✅ **Kompatibilitas tinggi** - Didukung semua browser
- ✅ **Kualitas bagus** - Cocok untuk foto profil
- ✅ **Standar web** - Format paling umum digunakan

## 📏 Rekomendasi Ukuran:
- **Foto Profil:** 400x400 pixels (square)
- **Banner:** 1200x300 pixels
- **Icon:** 64x64 pixels
